## 🇨🇳 中文

这个技能把产品图片、文字说明、图纸或可选的 3D 文件，变成 Blender 里一个完整的产品母模型，再据此产出广告底片、关键帧和 H3 成片。它从产品证据分析起步，先把图片、文字和图纸里的信息读懂，再动手建模。建完先做产品验证，通过之后才进入分镜；分镜基于真实模型生成，而不是凭空想象。分镜对手头资产逐镜核查，缺什么就补建什么。适用于实体产品广告、结构功能展示，以及已有产品片的修改；它不用概念图替代可编辑建模，所以模型后续仍能改、能复用。

### ✨ 能做什么

- 输入产品图片、文字、图纸或可选 3D 文件 → 输出 Blender 完整产品母模型
- 先做产品证据分析，读懂图片/文字/图纸再开始建模
- 产品验证先于分镜：模型过关才允许进入导演环节
- 基于实际模型生成广告分镜，不用概念图替代可编辑建模
- Shot Asset Check 逐镜核对资产，分镜驱动缺失部件补建
- 产出广告底片、关键帧与 H3 成片，并可修改已有产品片

## 🇬🇧 English

This skill turns product photos, text, drawings or optional 3D files into a complete product master model in Blender, then produces the advertising base film, keyframes and H3 final cut from that model. It starts with product evidence analysis — reading what the images, text and drawings actually say — before any modeling begins. Product verification comes next, and storyboarding only starts once the model passes. Storyboards are generated from the real model, so shots stay physically grounded. A per-shot asset check flags what's missing and drives rebuilds. Built for physical-product ads, structural and functional showcases, and revisions of existing product films; concept art never stands in for an editable model, so the asset stays reusable.

### ✨ What it does

- Product images, text, drawings or optional 3D files in → full editable Blender master model out
- Evidence analysis first: read the images, text and drawings before modeling
- Product verification gate before storyboarding — the model must pass first
- Storyboards generated from the actual model, never from concept art substitutes
- Shot Asset Check audits assets shot by shot and triggers rebuilds for gaps
- Delivers ad base film, keyframes and H3 final cut, with support for revising existing films
